A driving club, one link away.

Aeroline brings friends together for a drive without an account or installation. Pick a car, share a room code and cruise—or line up for a three-race Club Cup. Follow the checkpoints, collect points and come back for the next round.

Built on the open-source OpenRally engine, it combines physical tire and suspension behavior with approachable driving assists. The aim is simple: less setup, more time on the road.

From an idea to a shared world.

Built through iteration

I guided ChatGPT through requirements, implementation and repeated playtests with friends. Player feedback shaped the handling, boost, room flow and simpler driving UI. The difficult part was balancing multiplayer synchronization, graphics and usability.

The project was submitted to Handshake's Create a Multiplayer Game mission. The next priorities are broader device testing, steadier frame times and more consistent assets.

BEHIND THE BUILD

Small feedback. Better decisions.

01 / DEFINE

Start with the experience.

A public link, no accounts, friends on their own devices. Multiplayer was the reason to build—not a feature added at the end.

02 / PLAYTEST

Watch what breaks.

Friends tried the handling and room flow. Feedback exposed confusing menus, intrusive overlays and difficult slide recovery.

03 / REFINE

Make the road clearer.

Short control tips, simpler waiting screens and focused handling adjustments made the game easier to approach.

04 / SHARE

Leave the source open.

The repository includes editable code, tests, setup instructions and contribution guidance so the next improvement can come from someone else.

A few useful answers.

Do my friends need an account or an installation?

No. Open the public game, create a room and share the invite link or room code.

Is this a realistic simulator or an arcade racer?

It combines physical suspension and tire behavior with approachable driving assists. The emphasis is an enjoyable drive with friends rather than a professional simulation.

Can I play on a phone or with a controller?

Touch and controller controls are included. Desktop keyboard play is the most extensively tested; mobile layout, performance and physical-device testing remain active work.

Is the artwork above what the game looks like?

The coastal hero and map previews are loading or selection illustrations. Choose Actual gameplay or Multiplayer grid in the top gallery to see real screenshots.

Can I build or modify Aeroline?

Yes. The repository contains the editable source and local build instructions. Game code is MIT licensed; the website template and third-party assets have separate terms. Check their notices before distributing a fork.

Does this new project page change the game?

No. This is a separate portfolio and documentation site. The Play button opens the existing game; this page does not change its physics, cars, maps or multiplayer service.
