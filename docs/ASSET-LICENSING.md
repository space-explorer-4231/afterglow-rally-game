# Asset licensing

The root MIT license covers the code, including Aeroline's original code contributions, with OpenRally's original notice preserved. It is not a blanket license for every file used by the game.

| Material | Guidance |
| --- | --- |
| OpenRally and original Aeroline code | MIT; retain notices |
| Third-party vehicle bodies | Follow individual CC BY or CC0 notices, authors and modification records |
| Textures and environmental assets | Check the source and license in `ASSET-CREDITS.md` and bundled provenance |
| NCS recordings | Separate game-use and redistribution permissions may be required; not public domain |
| Original loading illustrations | Promotional artwork from the game's loading gallery; do not describe it as rendered gameplay |

Asset preparation reuses media from existing public deployment archives; copying a file does not grant new rights. Do not redistribute restricted recordings in your fork on the assumption that MIT applies. Obtain appropriate permission or replace them with your own or suitably licensed audio and update `source/src/config/festivalPlaylist.ts` and attribution.

Keep CC BY attribution, source links and modification descriptions with derived vehicle models. Real automotive names do not imply endorsement. Consult `ASSET-CREDITS.md` and model-level license files for provenance; resolve unclear rights before adding or redistributing an asset.
