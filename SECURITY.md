# Security

Do not publish credentials, private room data or an exploitable vulnerability in an issue.

Use **Security → Report a vulnerability** if the repository offers it. If unavailable, open an issue requesting a private reporting channel without including exploit details. Wait for a private channel before sharing reproduction steps.

Never commit environment files, Wrangler credentials, signing keys or access tokens. The example Cloudflare configuration omits the owner's account ID.

This independent project has no formal response-time guarantee.
